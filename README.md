# SANAD AI – Flutter MVP (Android)

هذه نقطة بداية فعلية لتطبيق سند، بواجهة عربية RTL وتصميم بسيط.

## الموجود في النسخة
- شاشة رئيسية عربية.
- تنقل بين الرئيسية والمساعد والكاميرا والموارد والإعدادات.
- إدخال صوتي عربي باستخدام speech_to_text (يتطلب صلاحية الميكروفون وخدمات التعرف على الكلام على الجهاز).
- قراءة الرد بصوت عبر flutter_tts.
- التقاط صورة بالكاميرا عبر image_picker.
- إعدادات أولية لتخصيص الاحتياجات وحجم النص والتغذية الصوتية.

## ما هو تجريبي حالياً؟
- ردود المساعد محلية توضيحية وليست متصلة بنموذج AI بعد.
- الصورة تُلتقط محلياً ولا تُرسل لتحليل الرؤية بعد.
- مكتبة الموارد تعرض تصنيفات فقط، ولم تُربط بمستودع ملفات موثوق.
- اختيار نوع الاحتياج واجهة أولية، ويحتاج ربطه بتخصيص فعلي لكل الشاشات.
- كلمة التنبيه «يا سند» والعمل الدائم في الخلفية غير منفذين. لا يمكن ضمان الاستماع المستمر على Android دون خدمة أمامية وإشعار دائم، واستهلاك بطارية، وتصميم خصوصية واختبارات توافق.

## التشغيل
1. ثبّت Flutter SDK و Android Studio.
2. أنشئ مشروع Flutter فارغاً أو استخدم هذا المجلد كمصدر مشروع.
3. من مجلد المشروع شغّل:
   ```bash
   flutter pub get
   flutter run
   ```

إذا لم يكن هيكل Android موجوداً، نفّذ `flutter create . --platforms=android` من داخل المجلد أولاً، ثم `flutter pub get`.

## صلاحيات Android
افتح `android/app/src/main/AndroidManifest.xml` وأضف قبل وسم `<application>`:
```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
```
قد تطلب بعض الأجهزة صلاحيات إضافية أو إعدادات خاصة بمزود التعرف على الكلام. اختبر على جهاز حقيقي.

## الخطوة التالية لربط الذكاء الاصطناعي
لا تضع API key داخل تطبيق Flutter. أنشئ Backend آمن (مثلاً Firebase Functions أو خادم خاص) يحتفظ بالمفتاح، ثم:
- نقطة `/chat` لاستقبال نص المستخدم وإرجاع الرد.
- نقطة `/vision` لاستقبال صورة بعد موافقة المستخدم وإرجاع وصفها.
- تحديد حدود الاستخدام ومعدلات الطلبات.
- سياسة خصوصية وحذف للصور والمحادثات.
